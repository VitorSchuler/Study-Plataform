## 📖 Sobre o Projeto

O **fokus.** é um *Hub de Aprendizado de Alta Performance* desenvolvido para estudantes que precisam de máxima eficiência durante sessões intensivas de estudo.

A plataforma combina:

- 🧠 Organização acadêmica
- ⏱️ Gestão inteligente de tempo
- 🤖 Assistência contextual via Inteligência Artificial
- 📂 Centralização de materiais
- 📈 Monitoramento de produtividade

Tudo isso dentro de uma interface minimalista inspirada em **Dark Tech / Cyberpunk**, com um modo claro baseado em estética industrial moderna.

---

## 🧠 Modus Operandi por Disciplina

O principal diferencial do **fokus.** é o sistema de **Modus Operandi por Disciplina**.

Em vez de utilizar um assistente genérico, cada disciplina possui um contexto próprio configurável.

### Fluxo

### 1. Cadastro da disciplina

Configure:

- Nome da matéria
- Professor responsável
- Diretrizes personalizadas de aprendizado

### 2. Personalização da IA

Exemplo:

> "Foque em resolução matemática passo a passo. Não entregue respostas finais diretamente. Utilize método socrático e análise assintótica."

### 3. Arena de Estudo

Ao acessar a disciplina, a IA recebe automaticamente essas diretrizes como contexto da sessão.

Resultado:

✔️ Respostas contextualizadas  
✔️ Maior profundidade técnica  
✔️ Menor necessidade de reexplicação  
✔️ Experiência personalizada por matéria

# 🚀 Executando Localmente

### Clone o projeto

```bash
git clone https://github.com/seu-usuario/fokus.git
```

### Entre na pasta

```bash
cd fokus
```

### Instale as dependências

```bash
npm install
```

### Execute localmente

```bash
npm run dev
```

Abra:

```text
http://localhost:5173
```
